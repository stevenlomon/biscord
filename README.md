## 🅱️iscord. Discord clone but make it scuffed and wonky :))

Giving yourself permission to just absolutely *suck* and have fun while doing so is one of the quickest ways to learn 🌱✨  
Learning project with focus on Backend and TypeScript built with AI primarily as a guide and infinitely patient Senior Dev for questions (the only use of pure vibe coding is in the TailwindCSS styling and some of the React components)  
Edit: The more I build on this, the more I realize that some of the things that are "bugs" and hurdles here in connecting backend with frontend are pre-solved for us and abstracted away when using a full stack framework like Next.js. A re-build in Next is definitely on the horizon haha! But I do genuienly believe that you can't fully appreciate these abstractions if you haven't manually built what is abstracted away yourself at least once first.
